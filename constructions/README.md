# Construction data

Each result is defined by a geometric construction and a finite collection of
exact inputs. The [catalogue](catalog/results.json) connects the dimension,
counting formula, source comparison and required files. Family directories
contain their mathematical data and verification programs.

The [research guide](../research/README.md) introduces the families.
The [reports](../reports/README.md) prove the geometric reductions, and
the [reproduction guide](../reproducibility/README.md) explains how to
run each finite check.

Inputs supplied by earlier work are identified in
[third-party materials](third-party.md). Recorded file identities distinguish
those sources from the distributed copies.

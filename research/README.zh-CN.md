# 构造是如何发现的

[English](README.md) · [结果](results.md) · [研究报告](../reports/README.md)

最终构造并不会自动说明通往它的道路。这里展开 Qiushi Engine 自主数学研究中的具体过程：
如何表示问题，计算揭示了哪些障碍，什么选择打开了新的搜索空间，以及获得的对象如何
形成可以证明的构造。

## 逐维探索与发现

逐维文档保留中间构造、具体搜索观察和改变方法的数学理由，并连接保存的支持交换、
设计生成数据、格向量与有理恒等式，使读者能将研究叙述与可重建的对象对应起来。

## 不同维度之间的联系

**不能直接补点，不等于构型刚性。** 25维移动的是一个保留的接触层，其对应伙伴已从赤道删除。
相同的横向几何给出保持块内距离的协同移动，之后只需两个局部修复即可容纳新点。

**分配方式也是构造变量。** 27维的相容候选池保持不变，但入选方向与三个标签一起改变。
即使原310方向选择不能直接补点，联合重选仍可得到更大的构造。

**共享冲突改变候选的价值。** 在32、33、34、39维，一个不能单独加入的支持，仍可能是
有价值的联合构造的一部分。选择的代价是旧阻挡集合的并集；33维最后一次交换分别计算有
二十次冲突，却只需删除九个旧支持。五元子集容量约束进一步控制新候选之间的相容性，
34维保存的搜索具体展示了这一过程。

**边界得到控制后，局部问题可以独立求解。** 35、36维的符号搜索识别出与外围只有有限
交叠的坐标区域，再用 Hadamard 变换将权四设计转移到权八问题。35维达到十一坐标模型
的容量；36维有直接的四色构造。37维的十二坐标区域只有部分支持不受外部阻挡，因此
需要重新选择源区组，而不能直接照搬36维的结果。

**改变母构造会显露尚未使用的空间。** 38维从 ERS 支持路线转向更大的 Leech 提升，
发现其赤道仍有补点空间。下一格壳提供尺度合适的新方向，最小范数论证统一保证新旧
相容性，留下的只是新方向之间的选择问题。

**选对小对象，可以控制大点集。** 43维利用母截面矩信息，确定一个具体子截面的正交壳
点数；45维则让矩不等式对一个可搜索纤维赋予正贡献。前者从嵌入中提取计数，后者把
显式见证转为下界，并用共同邻点图组织发现过程。

**一个母类的扩充可以传递到多个维度。** 八条新增 $P_{48p}$ 直线扩大49至55维共用的相容类，
像族选择再以精确并集为目标，利用不同尾码容量。49维直接体现母类扩充的收益，
较高维度还要控制不同像之间的重复。

这些联系没有把所有维度压进同一种搜索。支持码、局部符号集、另一壳层与截面嵌入，分别
揭示了扩大接吻构型的不同自由度。
